- Token-bucket rate limiting.
- Fallback routing.
- Circuit breakers.
- Usage budgets.
- Distributed tracing and metrics.

**Technology direction:** Python · FastAPI · Redis · OpenTelemetry · Prometheus · Grafana · Docker.

</details>
